# Taller de Unity · Escena invernal de rescate

Una patrulla queda semienterrada durante una tormenta de nieve. Las sirenas roja y azul siguen girando mientras el motor expulsa humo. La escena combina iluminación nocturna, jerarquías de objetos y sistemas de partículas.

## Cómo abrir la escena

1. En **Unity Hub**, agrega la carpeta del repositorio y ábrela con **Unity 6**. La versión exacta figura en `ProjectSettings/ProjectVersion.txt`.
2. Abre `Assets/Scenes/EscenaInvernal.unity` y pulsa **Play**.

El proyecto usa **Universal Render Pipeline (URP)**. El script `Assets/Scripts/SirenRotation.cs` gira las luces desde `Siren_Pivot`. Puedes cambiar la velocidad con **Rotation Speed** en el Inspector.
